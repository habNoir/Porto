# habNoir — Portfolio Website

Portofolio pribadi **Alwahab Dzulikroom Butudoka (habNoir)**. Siswa jurusan Rekayasa Perangkat Lunak (RPL) di SMKN 3 Palu, Vibe Coder, Fullstack Developer, dan Reverse Engineering enthusiast.

## 🚀 Tech Stack

- **Framework:** Next.js 16 (App Router) & React 19
- **Bahasa:** TypeScript
- **Styling:** Tailwind CSS v4
- **Desain & UI:** Estetika Yunani Kuno / Hermes (Nous Research) + Anthropic Archive, iOS Clear Glass, White & Platinum Accents
- **Ikon:** Lucide React

## 🛠️ Menjalankan Proyek

```bash
npm install
npm run dev
```

Buka `http://localhost:3000` di browser.

Untuk build versi produksi:

```bash
npm run build
npm run start
```
